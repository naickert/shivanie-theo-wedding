Invite Code Generator

Paste party names — one per line — and we’ll generate Crockford-base32 invite codes and shareable links.

Codes use the Crockford base-32 alphabet (32 characters, no I L O U). Each code is 5 random characters plus a mod-37 check character — kept consistent with js/guests.js#checkCharFor so the website’s validation accepts them. Randomness comes from crypto.getRandomValues.
